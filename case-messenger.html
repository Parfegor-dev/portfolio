Веб-мессенджер

Задача

Создать защищённую платформу для общения с поддержкой личных и групповых чатов, файлообменом и системой администрирования. Проект должен быть полностью рабочим и развёрнутым на сервере.

Функциональность

  • Личные сообщения и групповые каналы (включая канал «Общие новости» с правами только для администратора).
  • Загрузка файлов с валидацией по MIME-типам, переименованием в UUID и ограничением размера.
  • Бесконечный скролл с пагинацией.
  • Браузерные уведомления о новых сообщениях.
  • Административная панель: управление пользователями, сброс паролей, назначение прав.
  • Регистрация и аутентификация с хешированием bcrypt, CSRF-защита форм.

Технические детали

  • Бэкенд: Python 3.11, Flask, Flask-SocketIO (WebSockets для реального времени).
  • База данных: SQLite (разработка), для продакшена можно заменить на PostgreSQL.
  • Фронтенд: ванильный JavaScript, адаптивная вёрстка (CSS без фреймворков).
  • Безопасность: bcrypt, CSRF-токены на всех формах.
  • Деплой на VPS (Ubuntu): Gunicorn + Nginx, SSL (Let's Encrypt), systemd-сервис, UFW.

Результат

Рабочее приложение, развёрнутое на сервере. Кодовая база ~4000 строк. Проект демонстрирует навыки fullstack-разработки, работы с вебсокетами, безопасностью и администрированием сервера.
