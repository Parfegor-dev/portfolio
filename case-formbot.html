Form Bot — бот для сбора анкет

Задача

Создать безопасный и удобный инструмент для сбора анкет (опросов), который полностью соответствует требованиям 152-ФЗ о персональных данных. Пользователи должны давать явное согласие, иметь возможность удалить свои данные, а администраторы — легко управлять анкетами и публиковать их.

Функционал

  • Анкетирование: имя, возраст, состояние здоровья, часовой пояс.
  • Строгое соблюдение 152-ФЗ: запрос согласия при старте, кнопка «Я согласен» со ссылкой на политику, команда /delete_my_data для полного удаления всех данных.
  • Админ-панель: просмотр анкет, управление администраторами, настройка приветствия и сообщения после анкеты.
  • Публикация постов: можно создать пост с фото/видео и кнопкой «📝 Заполнить анкету» в любом из добавленных каналов.
  • Управление каналами: добавление каналов (по ID или через пересланное сообщение), удаление.
  • Уведомления администраторам о новых анкетах.

Технические детали

  • Python 3.11, aiogram 3.x (асинхронный фреймворк).
  • SQLAlchemy 2.0 (async) + PostgreSQL (продакшен), asyncpg.
  • Redis для FSM и хранения состояний.
  • Интеграция с Telegram Bot API для публикации постов и медиа.
  • Логика безопасной отправки длинных сообщений (разбивка на части).
  • Деплой в Docker (Dockerfile + docker-compose).

Результат

Готовый к внедрению бот. Исключены риски штрафов за нарушение 152-ФЗ, автоматизирован сбор анкет. Мои клиенты экономят часы ручной работы.
